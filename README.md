# SmartBudgetManager
A project for managing Budget.
This part explains to user what the workbook do , what need to use it and how to get started :
1 - SmartBudget Manager : is an Excel workbook designed to help users manage their monthly finances. 
2 – Requirements : 
-	Microsoft Excel 2016, 2019, 2021, Microsoft 365 . 
-	Basic computer skills.
-	The SmartBudget Manager Excel workbook.
3- Workbook Structure :
-	Transactions: Allows users to enter income and expenses.
-	Categories: Contains predefined expense categories such as Food, Transport, Rent, Health, and Education.
-	Dashboard: Displays monthly balance, total income, total expenses, and charts.
4 - Getting Started : 
-	Open the SmartBudget Manager Excel workbook.
-	Go to the Transactions worksheet.
-	Enter your income and expenses in the appropriate fields.
-	Select the correct category for each expense.
-	Open the Dashboard worksheet to review your financial summary.
